# rh-bridge
Rotorhazard backpack bridge. This simple tool is usefull to 
use a cheap ESP32 Dev Kit and connect it via network close 
to the pilots HDZero goggles.

![rh-bridge usage](https://github.com/clemix-fpv/rh-bridge/blob/readme/images/rh-bridge.png?raw=true)


# Installation:

You can install the python package via pip. 
```
python3 -m venv .venv
. .venv/bin/activate
pip install rh-bridge
```
